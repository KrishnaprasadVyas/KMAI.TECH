## ✦ Technical Architecture

Built with a focus on performance, minimal template bloat, and modern type safety:

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (with custom design tokens, clip-path utilities, and subtle grain overlay)
- **Kinetic Motion**: GSAP 3.15 + GSAP ScrollTrigger
- **Smooth Scrolling**: Lenis (synchronized with GSAP ticker)
- **Icons**: Lucide React + Bespoke geometric SVG branding
- **Accessibility**: First-class `prefers-reduced-motion` compliance, touch detection, and semantic HTML

## ✦ Key Features & Interactions

1. **Cinematic Preloader**:
   - Branded loading experience inspired by Dennis Snellenberg.
   - Large typographic counter (`00` → `100`).
   - Electric-blue progress beam.
   - Dynamic sequence: `IDEAS` → `SYSTEMS` → `IMPACT`.
   - Dual split-panel slide reveal into the homepage.
   - Session storage caching for snappy return visits.

2. **Dennis Snellenberg-Inspired Floating Cursor Preview**:
   - High-performance cursor tracking.
   - Floating project preview card with momentum-based rotation and tilt physics.
   - Row expansion with smooth typographic shifts.
   - Morphing cursor badges: `"VIEW PROJECT"`, `"EXPLORE"`, `"LET'S TALK"`, and magnetic button snap.
   - Mobile fallback: inline visuals for touch screens.

3. **Featured Flagship Showcase & Case Study Drawer**:
   - Spotlight on **Shri Gurudev Ashram** platform with parallax zoom.
   - In-depth modal / drawer displaying full system architecture, deliverables, production stack, and live project URLs.

4. **Interactive Capabilities & Services**:
   - 6 agency-grade capability tracks with expanding drawers and deliverables checklists.

5. **Monochrome Typography Technology Wall**:
   - Interactive technology grid with dynamic category filters and ambient blue glow on hover.

6. **Minh Pham-Inspired Editorial Testimonials**:
   - Oversized quotation typography, smooth sliding transitions, and structured placeholder schema (`TESTIMONIAL_PLACEHOLDER_01`).

7. **Production SEO & Meta**:
   - OpenGraph, Twitter cards, meta description, `robots.txt`, and `sitemap.xml`.

## ✦ Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v26)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/KrishnaprasadVyas/KMAI.TECH.git
cd KMAI.TECH

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
